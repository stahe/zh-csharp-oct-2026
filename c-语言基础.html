    3. C# 语言基础

    3.1. 引言

    我们先把 C# 当作一种传统的编程语言来对待。类将在下一章介绍。在程序中，有两个主要组成部分：

    • 数据；
    • 操作这些数据的指令。

    我们通常力求把数据与指令分离：

    本章的所有示例都是 单文件应用程序：一个单独的 [.cs] 文件，没有项目文件（[.csproj]），使用命令 [dotnet run basics-01.cs] 运行。该特性随 .NET 10 引入，已在上一章中介绍。示例位于课程代码的 [03-basics] 文件夹中。它们在法语区域设置（fr-FR）下运行，就像在法国的 Windows 机器上一样：实数使用小数逗号显示。

    • 第 6 行：在 C# 中，所有代码都属于某个类。这里的类名为 [Program]；
    • 第 9 行：静态方法 [Main] 是程序的 入口点：系统在启动时执行的就是这个方法。它的参数 [args]，接收命令行参数。

    上面列出了每种 C# 类型对应的 .NET 类型，如果该类型是结构则标记为 (S)，如果是类则标记为 (C)。可以看到，32 位整数有两个可能的名称：[int] 和 [Int32]。类型 [int] 是 C# 关键字。[Int32] 是属于 [System] 命名空间的结构：它的完整名称是 [System.Int32]。类型 [int] 是 C# 的 别名 ，指向 .NET 结构 [System.Int32]。同样，C# 类型 [string] 是 .NET 类型 [System.String] 的别名。[System.String] 是类，而不是结构。这两个概念相似，但有如下根本区别：

    • 结构类型的变量直接包含它的值：这称为 值类型；
    • 类类型的变量包含对象的地址（即它的 引用）；这称为 引用类型。

    • [nint] 和 [nuint] （C# 9）分别是有符号和无符号整数，其大小等于内存地址的大小：32 位系统上为 4 字节，64 位系统上为 8 字节。它们主要用于与本机代码交互；

    在源代码中，无论系统的区域设置如何，浮点数始终使用小数点书写。自 C# 7 起，整数可以用二进制书写（以 [0b] 为前缀），数字组之间可以用 _ 字符分隔以提高可读性：[1_000_000] 就是整数一百万。

    标准字符串字面量可以包含以 \ 字符开头的 转义序列 ："\n" 表示行结束字符，而不是 \ 和 n 这两个字符的序列，"\t" 表示制表符，"\"" 表示双引号，"\\" 表示 \ 字符本身。因此，要写 Windows 路径 c:\chap1\paragraph3，必须写成 "c:\\chap1\\paragraph3"。你也可以写成 @"c:\chap1\paragraph3"：@"text" 语法表示文本按所写原样采用，不解释 \ 字符。这称为 逐字字符串。

    C# 现在还提供另外两种字符串：

    • 插值字符串 （C# 6）$"..."：花括号中的表达式会被求值，其值会被插入字符串。表达式后可以在冒号之后跟一个格式说明符：[$"{d1:F2}"] 以两位小数显示浮点数 [d1] 。这是构造字符串最易读的方式，从现在起我们将使用它来代替 {0}、{1}…… 这样的格式；
    • 原始字符串 （C# 11）"""..."""：它以至少三个引号开头和结尾。它可以包含引号和未转义的 \ 字符，并且可以跨多行。结束引号之前的空格会从每一行中删除，因此文本可以与代码一起缩进。这对编写 JSON、SQL 或 HTML 非常有用。

    3.3.3. 数据声明

    3.3.3.1. 声明的作用

    程序处理的数据由名称和类型来刻画。这些数据存储在内存中。程序编译时，编译器会为每个数据分配一个内存位置，由地址和大小来刻画。编译器根据程序员所做的声明来完成这项工作。此外，这些声明还使编译器能够检测编程错误。例如，如果 [x = x * 2;] 中的 [x] 是字符串，该操作就会被判定为无效。

    3.3.3.2. 声明常量

    声明常量的语法如下：

    1
    const type name = value;

    例如：

    1
    const double VatRate = 0.2;

    为什么要声明常量？

    • 如果给常量起一个有意义的名称，程序会更易读；
    • 如果需要更改“常量”，修改程序也更容易。例如，如果增值税率变为 0.25，唯一需要修改的就是定义其值的那条语句：[const double VatRate = 0.25;]。如果程序中直接使用了 0.2，就需要修改许多条语句。

    常量的值必须在编译时已知：可以是数字、字符串、布尔值，或者能由其他常量计算出的表达式。按照约定，在 .NET 中，常量名以大写字母开头。

    3.3.3.3. 变量声明

    变量由名称标识，并与一种数据类型相关联。C# 区分大写字母和小写字母：变量 [END] and [end] 是不同的。

    变量可以在声明时初始化。声明一个或多个变量的语法是：

    1
    type variable1 = value1, variable2 = value2, ...;

    其中 [type] 是预定义类型或由程序员定义的类型。初始化是可选的；但是，C# 不允许使用尚未被赋值的局部变量。

    你也可以用关键字 [var] 代替类型，从而省略变量的类型：

    1
    var variable1 = value1;

    关键字 [var] 并不意味着变量没有确定的类型：它的类型就是赋给它的值的类型，由编译器确定。这里必须初始化，编译器才能推断出类型。当类型从值上显而易见时，我们使用 [var]。

    3.3.4. 可为 null 的类型

    值类型的变量（如 [int]）始终包含一个值。有时需要能够表示值 不存在：比如未知的年龄、数据库中的空字段。类型 [int?] （C# 2）就是在类型 [int] 的基础上增加了值 [null]，意为“没有值”。这称为 可为 null 的值类型。这一原理适用于所有值类型：[double?]、[bool?]、[DateTime?]，等等。

    引用类型的变量（如 [string]）始终可以取值 [null]：这表示它没有引用任何对象。如果试图使用这类变量的成员（例如它的属性 [Length]），就会导致运行时错误（[NullReferenceException]），这是 C# 中最常见的错误之一。从 C# 8 开始，编译器可以帮助预防这类错误：借助 可为 null 的引用类型——在使用 [dotnet new] 命令创建的项目和单文件应用程序中默认启用——

    • 类型 [string] 表示永远不会取值为 [null] 的字符串；
    • 类型 [string?] 表示可以为 [null] 的字符串。

    编译器会跟踪变量的可能取值，并在存在使用值 [null] 的风险时发出警告：例如把 [null] 赋给 [string] 变量，或者对未经检测的 [Length] 变量 [string?] 使用它，等等。与 [int?] 不同，[string?] 不会在运行时创建新类型：它是面向编译器的指示。

    3.3.6. 数据数组

    C# 数组是一个对象，可以把相同类型的数据归入同一个标识符之下。它的声明方式如下：

    1
    Type[] array = new Type[n];

    [n] 是数组可以包含的数据元素的个数。语法 [array[i]] 表示第 i 个数据元素，其中 i 属于区间 [0, n-1]。任何对数据项 [array[i]] 的引用，只要 i 不在区间 [0, n-1] 内，就会引发异常。数组创建时，每个元素都会被赋予其类型的默认值：数字为 0，布尔值为 [false] ，引用类型为 [null]。数组可以在声明的同时初始化：

    1
    int[] integers = new int[] { 0, 10, 20, 30 };

    或者更简单地写成：

    1
    int[] integers = { 0, 10, 20, 30 };

    或者，从 C# 12 起，使用 集合表达式：

    1
    int[] integers = [0, 10, 20, 30];

    从现在起我们将使用最后这种形式。数组有一个属性 [Length]，表示它包含的元素个数。

    二维数组的声明方式如下：

    1
    Type[,] array = new Type[n, m];

    其中 [n] 是行数，[m] 是列数。语法 [array[i, j]] 表示第 i 行的第 j 个元素。二维数组同样可以在声明的同时初始化：

    1
    double[,] reals = { { 0.5, 1.7 }, { 8.4, -6 } };

    每个维度的元素个数通过方法 [GetLength(i)] 获得，其中 i=0 表示对应第一个索引的维度，i=1 表示对应第二个索引的维度，依此类推。维数通过属性 [Rank] 获得，元素总数则通过属性 [Length] 获得。

    数组的数组（也称为 交错数组）的声明方式如下：

    1
    Type[][] array = new Type[n][];

    上面的声明创建了一个包含 n 个元素的数组。每个元素 [array[i]]，都是一个一维数组的引用。这些引用在上面的声明中并未初始化；它们的值为 [null]。与二维数组不同，每一行可以有不同的长度。

    C# 8 引入了两种便捷的表示法：

    • 从末尾索引：[array[^1]] 是最后一个元素，[array[^2]] 是 倒数第二个元素，依此类推。[array[^1]] 等价于 [array[array.Length - 1]]；
    • 范围：[array[1..3]] 是由索引 1 和 2 的元素组成的新数组。起始索引包含在内，结束索引不包含。边界可以省略：[array[2..]] 表示从索引 2 到末尾，而 [array[..^1]] 表示 从开头到倒数第二个元素（含）。

    3.4.1. 写到屏幕

    有多种向屏幕写入的指令：

    1
2
3
    Console.Out.WriteLine(expression);
Console.WriteLine(expression);
Console.Error.WriteLine(expression);

    其中 [expression] 是任何可以转换为字符串以显示在屏幕上的数据。所有 C# 或 .NET 对象都有一个 [ToString()] 方法，用来完成这种转换。[Write] 方法的作用与 [WriteLine] 相同，只是不换行。

    类 [System.Console] 提供对屏幕写入操作的访问（[Write]、[WriteLine]）。它有两个属性：[Out] 和 [Error]，它们是 [TextWriter] 类型的写入流：

    • [Console.WriteLine()] 等价于 [Console.Out.WriteLine()] ，向 [Out] 流写入，该流通常与屏幕关联；
    • [Console.Error.WriteLine()] 向 [Error] 流写入，该流通常也与屏幕关联。

    [Out] 流和 [Error] 流可以在运行时重定向到文件，我们稍后就会看到。

    3.4.2. 读取通过键盘输入的数据

    来自键盘的数据流由 [Console.In] 对象表示，其类型为 [TextReader]。这种类型的对象允许你使用 [ReadLine] 方法读取一行文本：

    1
    string? line = Console.In.ReadLine();

    [Console] 类提供了一个方法 [ReadLine]，它默认与 [In] 流关联。因此，你可以这样写：

    1
    string? line = Console.ReadLine();

    在键盘上输入的行（不含行结束字符）存储在变量 [line] 中，随后程序可以对其进行处理。正如我们已经看到的，当输入流耗尽时，[ReadLine] 返回 [null] ：这就是该变量是 [string?] 类型的原因。[In] 流可以像 [Out] 流和 [Error]流一样重定向到文件。

    2>>err.txt

    3.4.5. 将表达式的值赋给变量

    这里我们关注的是操作 [variable = expression;]。表达式可以是算术、关系、布尔、字符串等类型的表达式。

    3.4.5.1. 赋值操作的解释

    操作 [variable = expression;] 本身就是一个表达式，其求值过程如下：

    • 对赋值号右侧求值：结果是一个值 V；
    • 将值 V 赋给变量；
    • 值 V 同时也是该赋值的值，此时把赋值视为一个表达式。

    因此，操作 [V1 = V2 = expression] 是有效的。由于 = 运算符从右到左求值，我们得到 [V1 = (V2 = expression)]。表达式 [V2 = expression] 被求值，其值为 V。它的求值使 V 被赋给 V2。接着下一个 = 运算符被求值为 [V1 = V]。该表达式的值仍然是 V；它的求值使 V 被赋给 V1。因此，操作 [V1 = V2 = expression] 是一个表达式，其求值：

    • 使 [expression] 的值被赋给变量 V1 和 V2；
    • 返回 [expression] 的值。

    这可以推广到形如 [V1 = V2 = ... = Vn = expression] 的表达式。

    3.4.5.7. 运算符的组合

    [a = a + b] 可以写成 [a += b]；[a = a - b] 可以写成 [a -= b]。运算符 /、%、*、<<、>>、>>>、&、|、^ 同样如此。因此，[a = a / 2;] 可以写成 [a /= 2;]。

    3.4.5.8. 自增和自减运算符

    记法 [variable++] 表示 [variable = variable + 1] 或 [variable += 1]。记法 [variable--] 表示 [variable = variable - 1] 或 [variable -= 1]。在表达式中使用时，这些运算符有两种形式：

    • [i++] （后缀）：表达式的值是自增 之前 i 的值；
    • [++i] （前缀）：表达式的值是自增 之后 i 的值。

    3.4.5.9. 三元运算符 ?:

    表达式 [expr_cond ? expr1 : expr2] 的求值过程如下：

    • 先对表达式 [expr_cond] 求值。它是一个布尔表达式；
    • 如果为真，则表达式的值就是 [expr1] 的值，且不对 [expr2] 求值；
    • 如果为假，则情况相反：表达式的值是 [expr2] 的值，且不对 [expr1] 求值。

    如果 j > 4，操作 [i = (j > 4 ? j + 1 : j - 1);] 会把 j+1 赋给变量 i，否则赋 j-1。这等同于写成 [if (j > 4) i = j + 1; else i = j - 1;]，但更简洁。

    3.4.5.10. 运算符 ??、??= 和 ?.

    • [a ??= b] （C# 8）仅当 a 等于 [null] 时才把 b 赋给 a；
    • [a?.Member] （C# 6）在 a 为 [null] 时为 [null]，否则为 [a.Member]。因此，当 [text?.Length] 中的 [text] 等于 [null] 时不会导致错误；结果的类型为 [int?]。

    [Exit] 方法（属于 [Environment] 类）可以停止程序的执行：

    3.9. 枚举

    枚举是一种数据类型，其值域由一组具名的整数常量构成。设想一个需要处理考试成绩的程序。成绩有五种可能：Pass、FairlyGood、Good、VeryGood 和 Excellent。于是我们可以为这五个常量定义一个枚举：

    1

    1
    Honours myHonours = Honours.Pass;

    可以将变量与枚举中各个可能的值进行比较：

    3.10.1. 传递方式

    C# 支持以下传递方式：

    • 按值传递 （默认方式）：实际参数的值被复制到对应的形式参数中。这是两个不同的实体：如果函数修改了形式参数，实际参数保持不变。这种方式适用于函数的输入参数；
    • 使用 [ref] 按引用传递：实际参数和形式参数是同一个实体。如果函数修改了形式参数，实际参数也会随之被修改。关键字 [ref] 必须同时出现在函数定义和调用中。实际参数在调用之前必须有值。这种方式适用于输入输出参数；
    • 使用 [out] 按引用传递：与 [ref] 相同，但该参数是仅用于输出的参数：实际参数不需要初始值，并且函数必须为形式参数赋值。这是 [TryParse] 方法所使用的方式。从 C# 7 开始，可以在调用中声明变量：[out var x] 或 [out int x]；
    • 使用 [in] 按只读引用传递（C# 7.2）：参数按引用传递，从而避免复制，但函数不能修改它。这种方式只对较大的结构有用；对于预定义类型，按值传递同样高效。

    3.11. 局部函数和元组

    3.11.1. 局部函数

    局部函数 （C# 7）是在方法内部定义的函数，或者像我们的示例那样，定义在顶级语句之间的函数。它只能在该位置使用。由于我们的程序不再有类，局部函数取代了 2008 年示例中的静态方法。局部函数：

    • 可以在定义之前被调用；
    • 可以使用其周围的局部变量，除非它被声明为 [static]：[static] 关键字（C# 8）确保它只依赖于自己的参数，从而更容易理解。我们尽可能将局部函数声明为 [static] ；

    int min = values[0], max = values[0];
    foreach (int v in values)
    {
        if (v < min) min = v;
        if (v > max) max = v;
    }
    return (min, max);
}
