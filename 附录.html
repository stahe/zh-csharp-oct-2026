    15. 附录

    15.1. DBMS 与使用 Laragon 的 MySQL

    在 2008 年，课程附录介绍了 SQL Server 2005 Express 和 MySQL 5 的安装、它们的管理工具（MySQL GUI Tools）及其 ODBC 驱动程序，并配有约三十张截图。本文档的第 10 章和第 11 章只使用 MySQL 8，在 Windows 上安装它的最简单方法是安装 Laragon，这是一个便携的开发环境，其中包含 MySQL、图形客户端 HeidiSQL、配置好的终端、Apache 和 PHP 等。作者也在其 PHP 课程中使用它。

    15.1.1. 安装

    Laragon 可从 https://laragon.org 下载。安装过程是标准的；你可以保留建议的安装文件夹（[C:\laragon]）。Laragon 提供 MySQL 8（确切版本取决于 Laragon 的版本），带有无密码的管理员帐户（[root]），以及在本机上监听 3306 端口的服务器。本文档中的示例假定的就是这种配置，其中的连接字符串形如：

    1
    Server=localhost;Port=3306;Database=dbarticles;User=root;Password=

    如果 MySQL 是以其他方式安装的，并为 [root] 设置了密码，则必须在示例的连接字符串中用 [Password=] 替换它（[appsettings.json] 文件或程序顶部的常量）。

    对于没有 Laragon 的系统，你也可以从 https://dev.mysql.com/downloads/mysql/ 安装 MySQL Community Server，或者安装它的开源衍生版本 MariaDB。不过，这些示例只在 MySQL 8 上测试过：第 10 章的脚本使用了 MySQL 8 特有的排序规则（[utf8mb4_0900_ai_ci]），而第 11 章的示例向 Pomelo 传递了 MySQL 服务器版本（[MySqlServerVersion]）；如果使用 MariaDB，则需要调整这两点。

    15.1.2. 启动和停止 MySQL

    Laragon 主窗口包含一个启动服务器（Apache 和 MySQL）的 “Start All” 按钮和一个停止它们的 “Stop” 按钮。与 2008 年所述的 MySQL 5 安装不同，MySQL 不是在系统启动时运行的 Windows 服务：它只有在从 Laragon 启动时才会运行，这可以避免它在不使用时占用资源。Laragon 菜单（在窗口中右键单击）还允许你只启动 MySQL 并选择其版本。

    当 MySQL 没有运行时，第 10 章和第 11 章中的程序会因异常而失败，异常指出无法建立连接（“Unable to connect to any of the specified MySQL hosts”）：如果发生错误，这是首先要检查的事情。

    15.1.3. 命令行客户端

    Laragon 中的 Terminal 按钮会打开一个终端，其中可以使用 Laragon 的各个命令，包括 MySQL 命令行客户端 [mysql]。要连接到服务器，请使用：

    1
    > mysql -u root

    然后输入以分号结尾的 SQL 命令（[show databases;]、[use dbarticles;]、[select * from articles;]），并用 [exit] 退出。该客户端也可以运行 SQL 脚本，第 10 章就是这样创建其数据库的：

    1
2
3
    > cd csharp-oct-2026\10-adonet\sql
> mysql -u root < dbarticles.sql
> mysql -u root < dbtaxes.sql

    这些脚本每次运行时都会彻底重建其数据库：测试之后，你可以重新运行它们，把数据恢复到初始状态。

    15.1.4. HeidiSQL 图形客户端

    Laragon 的 Database 按钮会启动图形客户端 HeidiSQL，它取代了 2008 年的 MySQL GUI Tools（现已弃用）。首次启动时，HeidiSQL 会提供一个已为 Laragon MySQL 服务器配置好的连接会话（主机 [127.0.0.1]，用户 [root]，空密码，端口 3306）；直接打开它即可。你会看到：

    • 左侧是服务器数据库及其表的树状视图；
    • 右侧是若干选项卡，分别显示表的结构、表的数据（可以直接编辑），以及一个用于输入 SQL 查询的区域（“Query”选项卡），查询通过 [F9] 执行。

    要使用第 10 章中的脚本创建数据库，请在查询选项卡中打开该脚本（通过“File”菜单中的“Load SQL file”命令），然后执行它（[F9]）。你也可以使用 HeidiSQL 中的菜单创建数据库、用户和用户权限（右键单击连接 /“Create New”/“Database”；“Tools”菜单 /“User Manager”），但 SQL 脚本的优点是可重现、可重新运行。

    第 10 章和第 11 章使用以下数据库，它们都位于本地 MySQL 服务器上：

    10

    测试完成后，可以在 [mysql] 客户端中使用 SQL 命令 [drop database name;] 删除数据库， 或者在 HeidiSQL 中删除。
