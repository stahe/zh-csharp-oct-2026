    1.1. 2002 年至 2026 年的 C# 与 .NET

    C# 于 2002 年 2 月随 Microsoft 的 .NET 1.0 平台一同发布，二者密不可分。.NET 平台是一种类似于 Java 虚拟机的运行时环境：.NET 语言（C#、F#、VB.NET）的编译器生成中间代码（IL，“Intermediate Language”，即中间语言），由 .NET 虚拟机（CLR，“Common Language Runtime”，即公共语言运行时）即时编译为机器码。平台上的所有类对所有 .NET 语言都可用。

    2008 年的课程指出，.NET 只能在 Windows 上运行，Mono 项目使其可以在 Unix 和 Linux 上有限地使用。如今情况已发生了很大变化：

    • 2016 年：.NET Core 1.0。Microsoft 发布了 .NET 的一个新实现，它是开源的（MIT 许可证，代码可在 GitHub 上获取）并且是 跨平台的：Windows、Linux 和 macOS。旧的“.NET”框架（.NET Framework 4.x）仍然为遗留的 Windows 应用程序提供支持，但不再继续开发；
    • 2020 年：.NET 5。.NET Core 简称为“.NET”：一个适用于所有用途（控制台、Web、桌面、移动、云）的统一平台；
    • 自 2020 年起：每年 11 月发布一个新版本的 .NET。偶数版本（.NET 6、8、10）享有 长期支持 （LTS，三年）；奇数版本（.NET 7、9）享有 标准支持 （STS：十八个月，从 .NET 9 起延长至两年）。每个 .NET 版本都会带来新版本的 C#；
    • 2025 年 11 月：.NET 10（LTS）和 C# 14，本文档使用的就是它们。.NET 10 的支持期持续到 2028 年 11 月。

    2008 年的课程还指出，2002 年的 C# 在很大程度上是 Java 的翻版，两者之间很容易切换，但此后这两种语言各自形成了鲜明的特点。如今差距进一步拉大：在各个版本的演进中，C# 吸收了函数式语言的概念（lambda 表达式、LINQ、模式匹配、记录、不可变类型）、异步编程（[async] / [await]，JavaScript、Python 和 Rust 后来也采用了它），以及能在编译时检测空引用的类型系统。
