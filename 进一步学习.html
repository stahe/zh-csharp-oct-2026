    14. 进一步学习

    2008 年，课程以一份它未涉及的重要主题清单作结：LINQ、XML 文档处理、使用 ASP.NET 的 Web 编程，以及 .NET Remoting。现在情况已经不同：

    • LINQ 现已在第 5 章中讲解，它借助 Entity Framework Core 转换为 SQL 的内容在第 11 章中讲解；
    • Web 编程已在第 13 章中使用 ASP.NET Core 讲解；
    • .NET Remoting是 .NET 专有的客户端/服务器协议，在 .NET 中已不复存在（自 .NET Core 起）；它已被 REST Web 服务（第 13 章）、gRPC （基于 HTTP/2 的高效远程过程调用，其契约用 Protocol Buffers 描述）以及 SignalR （服务器与浏览器之间的实时双向通信）所取代。

    以下是以本文档为基础可以继续深入的主要主题。

    14.1. 处理 XML 文档

    JSON 在数据交换方面已在很大程度上取代了 XML，但 XML 仍在使用（配置文件、文档格式、现有的 SOAP 服务）。.NET 提供了两类 API：

    • LINQ to XML （[System.Xml.Linq]：[XDocument] 类、[XElement]、[XAttribute]）：最简单的一种，可使用 LINQ 构建和查询 XML 文档；
    • [System.Xml] 的类（[XmlReader]、[XmlWriter]、[XmlDocument]）以及 XML 序列化（[XmlSerializer]）。

    14.2. Web 应用程序

    第 13 章只讲解 Web 服务（生成数据的应用程序）。对于生成 HTML 页面的 Web 应用程序，ASP.NET Core 提供了：

    • ASP.NET Core MVC 和 Razor Pages：服务器端生成的页面；作者编写了课程 “ASP.NET Core MVC 框架分步入门”（2026 年 9 月）；
    • Blazor：用 C# 而不是 JavaScript 编写的交互式 Web 界面，可在服务器上或浏览器中（WebAssembly）运行。

    14.3. 桌面和移动应用程序

    关于 Windows Forms 图形用户界面的章节已从本文档中删除。Windows Forms 在 .NET 10 中仍然可用（用于 Windows），WPF 也是如此；.NET MAUI 使你能够为 Windows、macOS、Android 和 iOS 编写同一个应用程序。第 7 章（事件）和第 9 章（异步编程）中讲解的概念在这里可直接应用。

    14.4. 测试

    第 6 章介绍了 MSTest。另外两个测试框架也被广泛使用：xUnit 和 NUnit （2008 年的课程使用的是其 2.4 版，此后它已有显著演进）。单元测试通常还会辅以“mock”库（模拟对象）和针对 ASP.NET Core 应用程序的集成测试（[WebApplicationFactory]）。

    14.5. 性能

    自 .NET Core 以来，.NET 一直把性能作为重点。相应的工具包括：

    • [Span<T>] 和 [Memory<T>] 类型，它们无需复制即可操作数组或字符串的一部分（第 5 章）；
    • 提前编译为本机代码（Native AOT，[dotnet publish -p:PublishAot=true]）：生成独立的可执行文件，启动速度极快，代价是对反射有所限制（我们在第 5 章的 JSON 序列化中遇到过这些限制）；
    • 源生成器，它们在编译期间生成代码（第 5 章中生成的正则表达式，第 6 章中生成的 JSON 上下文）；
    • BenchmarkDotNet 工具，用于精确测量代码的性能。

    14.6. 部署

    .NET 程序可以通过多种方式部署：在计算机上已安装 .NET 平台的情况下（[dotnet publish]）、作为包含该平台的独立可执行文件（[--self-contained]），或者放在容器 中（[dotnet publish -t:PublishContainer] 无需 [Dockerfile] 文件即可直接生成容器镜像）。
